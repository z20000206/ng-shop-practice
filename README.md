# ng-shop-practice

Angular + NgRx 的實戰練習；主題為可擴充金流的小型商城（商品 CRUD、購物車、預留結帳）。

## 技術棧
- Angular（standalone、signals、SCSS）
- NgRx：Store / Effects / Entity / Router Store / Devtools
- json-server（模擬 RESTful 後端）

## 安裝
```bash
npm i

## 啟動
npm run dev
Angular: http://localhost:4200
API:     http://localhost:3000
